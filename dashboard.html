How the demo is capped

This is a public, shared workspace — no accounts, no keys. Every report runs the same 48-persona swarm (Llama 3.3 70B via OpenRouter) and is stored for everyone to see. To keep it free we cap it: $5/day total spend (a hard stop) and 8 reports/hour per visitor. When the daily cap is hit, new reports pause until 00:00 UTC.
